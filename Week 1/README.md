## 🚀 Getting Started

### Option 1 — Run locally

```bash
# Clone the repo
git clone https://github.com/yourusername/ds-fundamentals.git
cd ds-fundamentals

# Install dependencies
pip install -r requirements.txt

# Launch Jupyter
jupyter notebook
```

### Option 2 — Run on Google Colab

Click the badge below to open any notebook directly in Colab (no local setup needed):
